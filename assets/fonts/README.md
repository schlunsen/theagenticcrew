# Book fonts

Bundled so the PDF builds identically everywhere (`typst compile --font-path assets/fonts ...`)
and so the EPUB can embed them. Latin subsets from Fontsource.

| Family          | Use                               | Licence                  |
|-----------------|-----------------------------------|--------------------------|
| Source Serif 4  | Body text                         | SIL Open Font License 1.1 |
| Fraunces        | Display: titles, chapter numbers  | SIL Open Font License 1.1 |
| Inter           | Labels, running heads, page numbers | SIL Open Font License 1.1 |
| JetBrains Mono  | Code                              | SIL Open Font License 1.1 |
